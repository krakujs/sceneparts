# Code of conduct

We want SceneParts to be welcoming to everyone, whoever they are and wherever they're from.

- Be kind and assume good intent. Critique parts, not people.
- No harassment, insults, discrimination or sexual content, in issues, PRs, parts or anywhere else in the project.
- Respect other people's work: contribute only what you have the right to share.

Maintainers may edit or remove comments, close issues and PRs, and block people who break these rules. Report problems through a private report on the Security tab, or contact a maintainer listed in GOVERNANCE.md.

This code applies in all project spaces and when representing the project elsewhere.
